## English

Dashboard now shows your setup as one Java backend (LSPosed) and one Native backend (kmod, KPM, or Zygisk) instead of a per-module list, recognizes the new KPM backend, and warns when more than one native backend is installed — an error for the kmod+KPM combination, which can freeze the kernel
